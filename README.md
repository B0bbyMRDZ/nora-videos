# Puppy Days with Nora: Shorts

Finished vertical videos for @puppydays.with.nora (TikTok, Instagram Reels, YouTube Shorts).
Buffer pulls each video from its raw URL:
`https://raw.githubusercontent.com/B0bbyMRDZ/nora-videos/main/videos/<file>.mp4`

| File | Plan day | Topic |
| --- | --- | --- |
| video01-first-hour-home.mp4 | 1 | Do this before your puppy comes inside |
| video02-first-night.mp4 | 2 | Why your puppy cries the first night |
| video03-potty-schedule.mp4 | 3 | The potty schedule most owners skip |
| video04-puppy-biting.mp4 | 8 | What to do when your puppy bites |
| video05-accidents.mp4 | 11 | Never scold a puppy for an accident |
| video06-leash-pulling.mp4 | 24 | Your puppy pulls because it works |

- `tools/`: Pexels downloader, editor (teal #1F6F78 title boxes) and contact-sheet maker, copied from francesca-videos.
- `edits/`: clip CSVs and edit configs for each video.

B-roll comes from Pexels. The Pexels API key lives in a local `.env` and is never committed.
